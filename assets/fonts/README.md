# Self-hosted web fonts

- **Newsreader** (variable: optical size 6–72, weight 400–600, roman and italic) — © The Newsreader Project Authors, Production Type. SIL Open Font License 1.1. https://github.com/productiontype/Newsreader
- **Inter** (variable: weight 400–700) — © The Inter Project Authors, Rasmus Andersson. SIL Open Font License 1.1. https://github.com/rsms/inter

The `.woff2` files are the latin and latin-ext subsets served by Google Fonts, copied here so the site makes no third-party requests. Browsers download a subset only when the page uses characters from its `unicode-range`.
